## 六、核心业务模块职责说明

### 1. Player 类
- **职责**：管理玩家角色的状态和行为
- **属性**：
  - `name`：角色名称
  - `level`：角色等级
  - `hp`：角色血量
  - `exp`：角色经验值
- **方法**：
  - `fight()`：模拟战斗，增加经验值，减少血量
  - `get_status()`：返回角色当前状态的字符串表示

### 2. 主游戏循环
- **职责**：处理用户输入命令，协调游戏流程
- **支持的命令**：
  - `create <名字>`：创建新角色
  - `fight`：进行战斗
  - `status`：查看角色状态
  - `quit`：退出游戏
